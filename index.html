mini-seo-crawler v1.0 — python

Audit a website's technical SEO from one command.

Point it at a URL. It crawls the site, reads every title, canonical, heading, robots directive and image, then hands back a spreadsheet of exactly what is broken and how badly.

What it reads on every page

Response
Status code, final URL, redirect chain, response time, crawl depth
Indexability
noindex, X-Robots-Tag, canonical conflicts, robots.txt blocks
Title
Text, length, and whether another page uses the same one
Meta description
Text, length, duplicates across the site
Headings
H1 text and count, H2 count, pages with none or several
Canonical
Missing, self-referencing, or pointing somewhere else
Links
Internal, external and nofollow counts per page
Images
Total images and how many are missing ALT text
Content
Visible word count with scripts and styles stripped out
Markup
html lang, viewport, hreflang tags, JSON-LD schema types

How a crawl runs

Four stages, each in its own module, so any one of them can be tested on its own.

Fetch

A shared session with retries on 429 and 5xx, per-request timeouts, a capped response size, and a rate limiter every worker thread draws from. fetcher.py

Discover

Breadth-first from the homepage, staying on one domain. URLs are normalised first, so tracking parameters and fragments never cause the same page to be fetched twice. crawler.py

Parse

BeautifulSoup pulls out every on-page element listed above and turns it into a plain data object that knows nothing about HTTP. parser.py

Judge

Indexability is decided by a priority chain, duplicates are found across the whole crawl, and each problem is scored Critical to Low. analyzer.py
